# HabbitTracker

## Overview
HabbitTracker is a web application designed to help users track and maintain their daily habits. This application provides an intuitive interface for users to create, monitor, and analyze their habits over time.

## Features
- User account creation and authentication
- Habit tracking and monitoring
- Progress visualization
- Contact support system
- Responsive design for all devices

## Technologies Used
- PHP
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Installation
1. Clone the repository:
   ```
   git clone https://github.com/yourusername/HabbitTracker.git
   ```

2. Set up a local server environment (like XAMPP):
   - Install XAMPP from [https://www.apachefriends.org/](https://www.apachefriends.org/)
   - Place the project files in the `htdocs` directory

3. Start Apache and MySQL services in XAMPP control panel

4. Access the application through your browser:
   ```
   http://localhost/HabbitTracker/
   ```

## Usage
1. Create an account or log in
2. Add habits you want to track
3. Check in daily to mark habits as complete
4. View your progress over time
5. Contact support if you need assistance
